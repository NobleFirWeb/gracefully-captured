# Gracefully Captured

Website for Grace Sutherland Photography — a portrait, couple, engagement, and family photography studio based in Redding, California.

## Overview

Static HTML/CSS/JS site. No build step required. Hosted on GitHub Pages.

## Structure

```
/
├── gracesPhotography.html   # Homepage
├── about.html
├── services.html
├── contact.html
├── CSS/
│   ├── gracesPhotography.css
│   └── pages.css
├── JS/
│   └── gracesPhotography.js
└── img/
```

## Deployment

Served via GitHub Pages from the `main` branch root. Any push to `main` goes live automatically.

## Dependencies (CDN)

- [GSAP](https://gsap.com/) — scroll animations and page transitions
- [ScrollTrigger](https://gsap.com/docs/v3/Plugins/ScrollTrigger/) — scroll-driven effects
- [Swiper](https://swiperjs.com/) — gallery slider
- [Remix Icon](https://remixicon.com/) — icon set
- [Cormorant Garamond + Inter](https://fonts.google.com/) — typography
